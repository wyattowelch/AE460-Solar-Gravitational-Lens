How to Run:
A. Matlab Analysis
1) Download StructuralStressAnalysis.m file
2) Open MATLAB and open the StructuralStressAnalysis.m file.
• No additional toolboxes are necessary
3) Run the script
4) Review results in the Command Window

B. CAD Files
1) Download the zip folder fullsglcad.zip
2) Extract the content of the folder
3) Run Solidworks and open the assembly loacated in the folder or any of the individual parts

C. FEA Analysis
1) download the file firstrun.modfem
2) Run the FEMAP program and open this file in femap
3) Review the results sheet for analysis details
