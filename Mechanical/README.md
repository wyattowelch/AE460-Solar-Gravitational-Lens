How to Run:

A. Matlab Analysis
1) Download StructuralStressAnalysis.m file
2) Open MATLAB and open the StructuralStressAnalysis.m file. (No additional toolboxes are necessary)
3) Run the script
4) Review results in the Command Window

B. CAD Files
1) Download the zip folder fullsglcad.zip
2) Extract the contents of the folder to your computer's drive
3) Run Solidworks and open the assembly located in the folder or any of the individual parts
4) View and examine the various components

C. FEA Analysis
1) download the file firstrun.modfem
2) Run the FEMAP program and open this file in FEMAP
3) Review the results sheet for analysis details
