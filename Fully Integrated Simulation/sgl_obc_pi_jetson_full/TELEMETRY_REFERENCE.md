# Telemetry Reference

This document describes mission-store outputs generated by `sgl_pi_flight`.

Mission-store path:

- `<out_dir>/mission_store/`

Files:

- `telemetry_cycles.csv`
- `events.csv`
- `products_manifest.csv`
- `downlink_queue.csv`

## telemetry_cycles.csv

Cycle-level integrated telemetry.

Columns (in file order):

- `cycle`: simulation cycle index (OBC)
- `source_w`: EPS source power estimate (EPS module)
- `reserve_w`: configured reserve margin (OBC/EPS input)
- `total_bus_load_w`: total bus load including compute loads (EPS module evaluation)
- `noncompute_w`: ADCS+COMMS+Thermal+Propulsion+Payload power sum (OBC integration)
- `compute_budget_w`: available compute budget (EPS module)
- `jetson_allow_w`: OBC-allowed Jetson compute headroom after Pi load
- `scheduler_mode`: scheduler enum state from OBC (`0 nominal`, `1 throttled`, `2 suspended`)
- `adcs_mode`: ADCS mode string (star tracker/ADCS module via OBC wrapper)
- `adcs_power_w`: ADCS total power draw
- `wheel_power_w`: reaction-wheel power draw component
- `comms_power_w`: COMMS power draw
- `thermal_power_w`: thermal subsystem power draw
- `propulsion_power_w`: propulsion subsystem power draw
- `payload_power_w`: payload subsystem power draw
- `pi_power_w`: Pi/OBC compute-side draw used by scheduler budgeting
- `jetson_power_w`: Jetson assumed draw based on current job mode
- `jetson_mode`: `IDLE`/`ACTIVE`/`THROTTLED`/`SUSPENDED`
- `jetson_job_type`: `none`/`coarse`/`refine`
- `truth_pointing_err_deg`: closed-loop ADCS truth pointing error
- `est_pointing_err_deg`: estimator/filter pointing error estimate
- `tracker_conf`: tracker confidence
- `tracker_valid`: tracker validity flag (`0/1`)
- `tracked_stars`: number of tracked stars
- `comms_mode`: COMMS mode string
- `comms_backlog_bits`: queued downlink backlog bits
- `payload_mode`: payload mode string
- `payload_active`: payload active flag (`0/1`)
- `dataset_ready`: payload dataset-ready flag (`0/1`)
- `dataset_id`: latest/current dataset identifier
- `dataset_count`: count of datasets generated
- `acquisition_stage`: payload acquisition stage counter
- `active_stage`: currently active progressive processing stage index
- `active_stage_n`: output resolution of active stage
- `roi_count`: ROI count for active stage
- `processing_queue`: remaining processing stages in queue
- `thermal_mode`: thermal mode string
- `heater_active`: heater on/off flag (`0/1`)
- `thermal_temp_c`: thermal representative temperature
- `propulsion_mode`: propulsion mode string
- `propulsion_active`: propulsion active flag (`0/1`)
- `propulsion_thrust_n`: propulsion thrust value
- `camera_mode`: payload camera/input mode (`synthetic_image`, `image_file`, `pi_camera_demo`)
- `camera_frame_ready`: camera/file frame was acquired and decoded (`0/1`)
- `alignment_valid`: marker-based alignment succeeded (`0/1`)
- `alignment_score`: alignment confidence score
- `blur_score`: focus/sharpness score (Laplacian variance proxy)
- `brightness_mean`: mean luminance
- `contrast_score`: luminance standard deviation
- `raw_capture_path`: path to raw captured/loaded frame
- `rectified_image_path`: path to rectified/normalized target image used for dataset generation

### Dashboard grouping

Current dashboard group mapping (`tools/telemetry_dashboard/core.py`):

- `Power/EPS`: source, noncompute, compute budget, total bus load, scheduler mode
- `ADCS`: adcs/wheel power, truth/estimated error, tracker confidence/valid/stars
- `Thermal`: thermal power, heater active, thermal temp
- `Propulsion`: propulsion power, active flag, thrust
- `Payload`: payload power, active, dataset ready/count, acquisition stage
- `COMMS`: comms power, backlog bits
- `Jetson/Processing`: jetson power, roi count, processing queue
- `Other`: auto-detected columns not in explicit mapping

## events.csv

Append-only event timeline written by OBC.

Columns:

- `cycle`: cycle when event was emitted
- `event_type`: machine-readable event type string
- `severity`: `info`/`warn`/`error`
- `message`: human-readable description
- `value`: optional value/context

Event types currently emitted:

- `jetson_unavailable`
- `scheduler_mode_changed`

- `jetson_coarse_failed`

- `jetson_refine_failed`
- `adcs_correction_started`
- `adcs_correction_stopped`

## products_manifest.csv

Authoritative Pi-owned product record.

Columns:

- `cycle`: cycle when product was recorded
- `dataset_id`: dataset identifier
- `stage`: progressive stage index
- `kind`: product type. Current image-file/annulus runs use `recon_base`, `recon_upscaled`, and `recon_refined`; legacy/debug paths may still emit `coarse` and `refined`.
- `out_n`: output resolution for stage
- `path`: product path
- `bytes`: output product size (bytes)
- `roi_count`: ROI count used/selected for the stage
- `roi_score_mean`: mean ROI score
- `status`: processing result status string

## downlink_queue.csv

Pi-owned downlink queue entries derived from produced artifacts.

Columns:

- `cycle`: enqueue cycle
- `dataset_id`: dataset identifier
- `priority`: queue priority (lower number is higher priority in current convention)
- `bits`: estimated bit cost for downlink
- `kind`: product kind, matching manifest product semantics.
- `path`: artifact path
- `status`: queue status (currently `QUEUED`)

## Subsystem Ownership Summary

- OBC integration/orchestration: scheduler, FDIR, queueing, manifests, event/telemetry file writes
- EPS module: source/load/budget/bus calculations
- Star tracker/ADCS module: tracker+gyro+estimation+control+wheel-loop metrics
- Thermal module: heater/thermal state and thermal power
- Propulsion module: propulsion mode/active/thrust/power
- Payload module: dataset readiness/state/power and acquisition progression
- COMMS module: comms mode/power/backlog/downlink state
- Jetson worker: coarse/refine processing execution and result payloads
